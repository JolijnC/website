*Note* Deze les draait niet om programmeren.

### Doelgroep
Deze les is bedoeld voor leerlingen in de bovenbouw van havo/vwo die wiskunde B hebben. 

### Opbouw
Deze les bestaat uit een presentatie gegeven door mij afgewisseld met een interactief practicum.
Normaal gesproken kost deze les ongeveer 1.5 uur (twee lesuren is wel nodig).  

### Locatie
Deze les kan zowel op de universiteit als op de middelbare gegeven worden (zolang ik er kan komen met het openbaar vervoer).

### Inhoud
Deze les bestaat uit een presentatie over:
* Introductie over coderen. 
* Uitleg over binaire coderen van het alfabet en afstanden tussen codewoorden  
* Uitleg over de Hamming Code.

Het practicum bestaat uit:
* Opgaves over de onderwerpen van de presentatie.
* Het encoderen van een tekst, fout erin verwerken, decoderen (interactief).
